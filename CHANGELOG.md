# Changelog

All notable changes to the Market Intelligence Harness are recorded here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Dates are when the work landed; this project doesn't use version numbers yet, so
entries are grouped by date with an **Unreleased** section for work in progress.

## [Unreleased]

### Added
- **AI Subagent Harness** (`modules/harness/`, new) — the synthesis layer and project end-goal, served at `/harness.html`. Every data module casts a signed **vote** (`votes.py`, one fail-soft `vote_<domain>()` per module reusing its existing entrypoint); a **deterministic, LLM-free combiner** (`combiner.py`) sums `direction × conviction × weight × stance_factor`, applies **regime arbitration** (HEALTHY + rotation-on → ROTATE; deteriorating or rotation-off → CONCENTRATE, halving the RRG rotation bet) and a cross-domain **sector confluence** bonus, and Claude **narrates** one daily brief — *math decides, the LLM explains*. The LLM layer (`agents.py`) shells out to the local **`claude` CLI on the user's subscription** (no API key, no per-token cost) and **fails soft to deterministic templates**, so the whole thing runs at `$0`/offline. On-demand + cached (memory TTL + `data/brief_<date>.json`); the hub badge reads cache only. **Phase 2 — the Referee** (`backtest.py`): emits the harness's own point-in-time call panel and A/B's the *combined* decision against raw RRG and SPY/RSP-matched beta through the existing `rrg/backtest.py` machinery (finding: no absolute alpha over beta in a concentration regime, but regime-arbitrated confluence sharpens the *relative* signal vs raw RRG). **Phase 3 — Watchlist suggestions + paper trading** (`watchlist.py`/`picks.py`/`paper.py`): upload a TradingView watchlist → ranked **impulse × hold-ability** suggestions (a great setup on a junk stock scores low; a great stock with no setup isn't a buy-now) feeding two cost-modeled **paper books** run side-by-side (long-only + hedged long−SPY) whose hedged cost-adjusted return vs SPY is the gate. **Phase 4 — Trading Mode**: a Manual ⇄ Autonomous toggle — autonomous runs a `paper_poller.py` daemon that idempotently steps the paper book once per trading-day close; manual adds a **grounded AI-assist chat** (`chat.py`) that answers only from the deterministic state. Real broker order placement stays out of scope. CLI: `python3 -m modules.harness.cli [--llm] [--backtest] [--picks] [--paper] [--chat "q"]`. Unit-tested across `tests/test_harness*.py` (no network; the `claude` subprocess + prices mocked/injected).
- **Research module** (`modules/research/`, new) — the Research subagent at `/research.html`. Its headline is a **per-ticker fundamental conviction read**: a pure `fundamental_score(row)` blends six self-contained sub-scores (growth, demand/accumulation, institutional sponsorship, valuation, trend, relative strength) into a **0-99 + Strong/Solid/Mixed/Weak verdict**, attaches the name's sector-rotation + macro-regime context, and has Claude write a bull case / risks / what-would-change-the-view note (fail-soft template fallback). It **wires into the harness pick HOLD axis** (`picks._hold` blends `fund_score`, `FUND_BLEND=0.45`) so a name's fundamental conviction flows into its paper-trade size, and the harness chat grounds on it. Also does **sector/theme primers** (overview + competitive landscape + peer comps + ideas shortlist) as a secondary lens. Pure composition — *math gathers/scores, Claude only writes the prose*; adds **no harness vote**. Unit-tested in `tests/test_research.py` (no network/LLM).
- **CANSLIM module** (`modules/canslim/`, new) — O'Neil/IBD's **7-factor growth scorecard** at `/canslim.html`, a market-direction banner + a **0-99 leaderboard** with the C-A-N-S-L-I-M letter breakdown per stock. **Pure composition, no new quant**: each letter reads an existing signal (C/A ← screener EPS growth, N ← % from 52w high, S ← accumulation A-D + small-float bonus, L ← a cross-sectional RS rating, I ← the confluence institutional leaf, M ← breadth regime as a per-stock multiplier + banner). Composite is a weighted average renormalized over the *available* letters (fail-soft — works before fundamentals finish syncing). Unit-tested in `tests/test_canslim.py`.
- **Options Flow module** (`modules/flow/`, new) — unusual options activity (whale entries/exits) at `/flow.html`, encoding a flow trader's **6-rule filter** (`scoring.py`, pure) over **Schwab option-chain snapshots** via a pluggable `source.py` adapter (a future Polygon trade tape upgrades the two tape-only signals with zero scoring change). A singleton poller (`poller.py`) diffs snapshots for volume deltas + clusters, scores with Rule-6 confluence (sector RRG call + breadth regime + golden pocket + volume-profile zone), persists non-noise signals, dispatches alerts (reuses the screener's Discord/SMTP senders), and runs a next-morning OI-confirmation pass (entered vs exited). Frontend has a default-ON "conviction only" toggle (the 90%-noise cut), per-rule filters, an ESTIMATED-aggressor badge, and per-contract factor drill-down. Honest caveats (snapshots not the tape → aggressor estimated, T+1 entered/exited) surfaced in the UI. Unit-tested in `tests/test_flow_scoring.py` + `tests/test_flow_store.py`.
- **News & Macro Events module** (`modules/news/`, new) — a news & macro-events tracker at `/news.html`, built free-first / fail-soft (works with **zero keys**, free keys enrich it). Four live tabs: a **week-by-week Economic Calendar** (FOMC static table + FRED econ releases with Actual/Previous when keyed, else an approximate generator), an **Earnings** calendar (Finnhub broad + EPS if keyed, else focus-list), a **News feed** (CNBC/MarketWatch/Yahoo RSS + SEC 8-K + AlphaVantage/Polygon sentiment), and a **Rates & Curve** tab (Treasury yields, fed funds, curve inversion from FRED). Exposes an **`event_risk()`** hook that schwab/breadth overlay as an amber banner (frontend fetch, no backend cross-import). Fed-funds-rate *probabilities* deliberately deferred (context not alpha). CLI: `python3 -m modules.news.cli`. Unit-tested in `tests/test_news_calendar.py` (no network).
- **Confluence factor layer** (`modules/confluence/`, new) — a **routeless shared factor library** of pure leaves (numpy/pandas only, no I/O, no upward imports) at the bottom of the dependency order. The `flags`/`exhaustion` leaves were **moved here from `rrg/`** (single source of truth, shared with the screener's vectorized panels + the flag backtest). New leaves: **`volume_profile`** (volume-at-price → POC/VAH/VAL/HVN/LVN + a D/P/b/B/trend shape → a signed discount/premium contribution), **`accumulation`** (U/D volume ratio + Chaikin A/D divergence + accum/distrib days → an A-E rating, the institutional buy/sell footprint), and **`institutional`** (CANSLIM's I — ownership %-held + holder-count QoQ trend → a sponsorship score). The cohesive **wave engine** (`wave.py`) — significant-swing ZigZag, golden-pocket/wave-3/5 Fib structure, the ABC corrective family, dual RSI divergence — was extracted verbatim from `rrg.signal`, guarded by a **golden-master test** (`tests/test_rrg_golden.py`). Each factor emits a signed contribution the RRG `_conviction` engine sums and the flow tool reads as Rule-6 context. Unit-tested across `tests/test_confluence_*.py`.
- **Macro Regime module** (`modules/macro/`, new) — the "signals of health" backend modeled on AskLivermore, Phase 1 (backend + tests). A **deterministic growth×inflation 4-quadrant regime classifier** (`regime.py`): two self-normalized z-score axes (growth = copper/gold, tight credit, cyclicals>defensives, small caps, falling jobless claims, breadth; inflation = 10Y breakeven, copper, energy leadership, gold) mapped through a sigmoid → **Goldilocks / Reflation / Stagflation / Disinflation as probabilities** (products that sum to 1), with confidence, shift-risk (top-2 margin), a driver line, a plain-English playbook, and a probability-weighted equity tilt. Plus **Leading + Macro indicator panels** (`indicators.py`): yield curve, credit spreads, sector leadership, breadth, VIX, momentum, small caps, tech / new-highs-lows, A/D, copper/gold, vol spread, 10Y-2Y, VIX term structure, jobless claims, McClellan — each a value + 20-bar Δ + STABLE/COMPLACENT/WATCH/TURNED state + a templated plain-English meaning. **Liquidity/credit additions:** HYG/SPY (high-yield credit confirming vs diverging from equities), US Dollar/DXY (`DX-Y.NYB`→`UUP` — a strengthening dollar tightens financial conditions, and feeds *both* regime axes since it's the reflation↔disinflation lever), and Bitcoin (`BTC-USD` as a global liquidity / risk-appetite proxy, feeding the growth axis; the panel is filtered to trading days so BTC's weekend bars don't shift the as-of date). Data via `sources.py` (one batched yfinance pull through `rrg.signal._fetch_close` + FRED via `news.sources.fred_observations` + `breadth.build_summary`, all lazy/fail-soft, TTL-cached). Served at `/macro.html` (standalone detail page) with a hub card + harness cross-nav; routes `GET /api/macro`, `/api/macro/summary` (cache-only badge), `POST /api/macro/refresh`. Deterministic + $0; the LLM only interprets it. Unit-tested in `tests/test_macro.py` (no network).
- **Harness page → the Market-Intelligence Dashboard (AskLivermore-style, Phase 2).** `harness.html` was reworked from a brief-only page into the full single-page dashboard: the stance banner + plain-English brief, then **"What You Need to Know"** cards (Where Are We / Too Late to Buy / Buy the Dip / When Does It End / Hidden Risk — deterministic plain-English reads added to the macro `build_dashboard` output as `cards`), the **Market Regime** probability panel + **Market Health** stats, the **Leading + Macro Indicators** tables, and **Themes This Week** (top/bottom-5 themes by weekly RS vs SPY), followed by an **"Engine Room"** section holding the existing confluence chips, per-domain vote cards, and referee A/B. The page composes three independent fail-soft fetches (`/api/harness` + `/api/macro` + `/api/themes`) so one slow/missing module degrades a single panel, never the page.
- **Harness — macro regime vote + plainer brief.** A 9th domain vote (`votes.vote_macro`, weight 18, second to breadth) feeds the growth/inflation regime's equity tilt into the deterministic combiner, with the full regime + caution indicators in `detail`. The master-brief prompt was rewritten to speak **plain English with a punchy headline** and to *interpret* the data (expert insight, anchored to the deterministic stance/score/regime), weaving in the macro backdrop + market health; the `$0` template fallback also surfaces the macro backdrop.
- **Breadth** — `build_summary` now exposes raw `advances`/`declines` counts (backward-compatible) for the macro A/D indicator.
- **Breadth Tape** — a Stockbee-style **Market Monitor** as a second tab on the breadth page (`/breadth.html`): a dense daily table (newest day on top) of raw breadth counts — stocks up/down 4% today, 5/10-day ratios, up/down 25%+ over a quarter, up/down 25%+ & 50%+ over a month, up/down 13%+ over 34 days, a 10× ATR extension count, % above the 50-day MA, the stock-universe count, and the S&P (^GSPC) close — each cell green/red heat-colored, with Advancing/Declining and New-High/New-Low gauge bars and a **Copy as image** button (clipboard PNG). Scope toggle (All NYSE+Nasdaq default / S&P 500 / NYSE / Nasdaq); computed on demand from stored bars and reused across the existing breadth math. - **Screenshot capture script** (`scripts/capture_screenshots.sh`) — Safari + macOS `screencapture` (no extra deps) to snapshot every page straight into `assets/` (the same files the READMEs embed as each module's hero).
- **Themes module** (`/themes.html`) — track your own **theme baskets**. Create / rename / delete themes and edit their tickers right in the page (SQLite-backed). Six themes seeded: Optics & Photonics, Data Centers, Software, Defense, Space, AI Biotech. ## [2026-06-15]

### Added
- **Empirically-weighted, regime-aware flag patterns** — the RRG conviction engine now weights its bull/bear flag factor by the flag's *measured* edge (`win_rate − 0.5`), per-symbol where there's enough history else a basket default, and zeroes a flag that opposes the market regime (bear flags fail upward in bull markets). Detection core extracted to a shared `flags.py` leaf; `flag_backtest.py` gains a `--regime` conditioned study. Per-stock flag win-rates are background-precomputed (incremental, **~90-day per-symbol cache**) and surfaced next to each name on the **Rankings** and **Themes** pages.
- **Volume buyer/seller exhaustion** — a volume *climax* into a new high/low that closes weak/strong flags a topping/bottoming, added as a confluence factor to the RRG conviction engine (on each symbol's own price+volume, since the RS line has none) and as a screener field.
- **Flag + exhaustion screener fields** — filter by `flag` (bull/bear/none) and `exhaustion` (buyer/seller/none), with seeded **Bull Flag / Bear Flag / Selling Climax / Buying Climax** screens.
- **Backtester: toggleable universe + benchmark, regime split, and gate.** The RRG Strategy Backtest tab adds a **universe** toggle (11 sectors / ~40 sector+industry ETFs / ~34 de-correlated), a **benchmark** toggle (SPY cap-weight / RSP equal-weight), a **rotation-regime split** (RSP/SPY trend) on the forward-return study, and a **per-symbol contribution** breakdown (top-3/top-5 share — is the curve broad or carried by a few names?).
- **Rotation-regime gate** — conviction is suppressed when the market is in a concentration regime (RSP/SPY below its trend, where a rotation signal structurally can't win). It's no-lookahead, so it gates the backtest too: on the 40-ETF set it cut max drawdown roughly in half and made the strategy beat the exposure-matched benchmark. Validated out-of-sample — the ROTATE IN − ROTATE OUT separation holds up across walk-forward folds.

### Changed
- **⚠️ w5 extended is no longer a backtest exit.** The larger study showed it has *positive* forward excess (continuation, not exhaustion), so exiting a long on it was selling winners early; it stays a cautionary late-cycle badge / Schwab TRIM but no longer forces an exit.
- Fixed a string-date vs Timestamp index mismatch that had silently nulled the breadth-regime conditioning.

> Honest caveat surfaced by this work: the backtest's headline equity is concentration-driven (a banks theme + a few small-sample winners), but the *relative* ranking edge (ROTATE IN beats ROTATE OUT) is real and holds out-of-sample. Use the tool as a rotation **ranking**, gated to rotation-on regimes — not as a literal absolute-return strategy. Next step (planned): a long/short or top-N-minus-bottom-N rotation sim to monetize that relative edge.
