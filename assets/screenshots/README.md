# Screenshots

These images are **generated** — run the capture script (Safari + macOS `screencapture`, no extra deps):

```bash
python3 app.py                          # in one terminal
bash scripts/capture_screenshots.sh     # in another
```

It writes one PNG per page here: `home.png`, `rrg.png`, `breadth.png`, `breadth-tape.png`,
`schwab.png`, `screener.png`, `rankings.png`, `themes.png`. The module READMEs reference these
paths, so the images appear once the script has run. Re-run any time to refresh.
